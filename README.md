# Project Name

**The Aurelian** — A modern luxury boutique hotel website prototype.

---

## Purpose

This project is a hospitality website concept built to demonstrate responsive design, hotel UX best practices, brand identity, and WordPress-ready section architecture for independent hotel opportunities.

> ⚠️ **Status:** Prototype / frontend demo. Not a completed client WordPress project.

---

## Hotel Brand Concept

- **Name:** The Aurelian
- **Location:** 2400 Post Oak Blvd, Houston, TX 77056 (Galleria District)
- **Tagline:** "Where stillness meets splendor"
- **Vibe:** Ultra-luxury boutique, intimate, refined
- **Target guest:** Affluent leisure travelers, couples, luxury business travelers

---

## Tech Stack

- **Next.js 16** (App Router, TypeScript)
- **React 19**
- **Tailwind CSS v4**
- **Framer Motion** (subtle entrance animations)
- **Lucide React** (icon library)
- **next/font** (Google Fonts: Playfair Display + Inter)

---

## Sections Included

| Section | Description |
|---|---|
| Navigation | Fixed, blurred glass nav with smooth scroll links |
| Hero | Full-screen cinematic hero with brand imagery and dual CTAs |
| Booking Bar | Check-in / check-out / guests mock booking bar |
| Rooms & Suites | 6 room types with pricing, size, and amenity details |
| Amenities | Spa, dining, pool, fitness, valet — icon grid + feature cards |
| Local Experiences | 6 curated Houston-area POIs with category and distance |
| Gallery | Editorial image grid (gallery section) |
| Testimonial | Single featured guest quote with star rating |
| Special Offer CTA | Direct booking promotion with savings callout |
| Footer | Contact, address, social links, quick navigation |

---

## WordPress Implementation Path

This prototype can be converted into WordPress using:

- **Custom WordPress theme** — Full control, theme development required
- **Gutenberg block-based sections** — Reusable content blocks for rooms, amenities, gallery, offers
- **Elementor or Bricks** — Visual page builder for staff-friendly edits
- **Headless WordPress + Next.js frontend** — WordPress as CMS, Next.js as frontend

**Editable areas for hotel staff:**
- Room descriptions, pricing, images
- Amenity icons and descriptions
- Gallery images and captions
- Special offer text and eligibility
- Local experience entries
- Testimonial quotes
- Contact information

**Booking functionality:**
Connect through the hotel's existing booking engine, PMS, embedded widget (Cloudbeds, Little Hotelier, rezOvation), or third-party reservation system.
